# مستخلص إسلام

نظام مستخلصات المقاولين ولوحة تحليل المشاريع.

## الفكرة

- **الحساب** = جهة (مقاول/مورد) تعمل نوع عمل معيّن داخل مشروع. الدفعات وبنود الأعمال والمستخلصات كلها تتبع الحساب.
- **المستخلص تراكمي** بنفس شكل مستخلصات م. إسلام: سابق / حالي / جملة × السعر = قيمة الأعمال، الإجمالي − ما سبق صرفه = المستحق.
- **دفعات الصندوق** هي الحقيقة المالية. مستخلصات إسلام القديمة (Word) تُربط بحسابات الصندوق من صفحة المطابقة فتنسحب بنودها.

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | لوحة التحليل: الإجمالي، أعلى مشروع/جهة/نوع عمل/بند، شهري/سنوي، فلاتر |
| `/certificates/new` | مستخلص جديد: مشروع → مقاول → حساب → بنود سابقة كاملة → حالي → حفظ → اعتماد → طباعة |
| `/accounts` | كل الحسابات مع الفلاتر؛ تفاصيل الحساب: بنود، دفعات، مستخلصات |
| `/payments/new` | تسجيل دفعة صندوق |
| `/reconciliation` | (مدير) ربط مستخلصات إسلام القديمة + مراجعة الحسابات المعلّمة |
| `/settings` | (مدير) مشاريع، دمج الجهات، أنواع العمل، كلمات المرور، تصدير Excel |

## التشغيل

```bash
npm install
cp .env.example .env   # ثم عبّئ DATABASE_URL (Neon) وكلمات المرور
npm run db:push        # إنشاء الجداول
npm run import         # استيراد ملفات data/raw (Word لإسلام، Excel للصندوق) — يمسح ويعيد التحميل
npm run dev
```

المستخدمون الافتراضيون: `admin` (مدير) و `islam` (مستخدم) — كلمات المرور من `.env`.

## النشر على Netlify

اربط المستودع، وأضف متغيرات البيئة `DATABASE_URL`, `SESSION_SECRET`, `ADMIN_PASSWORD`, `USER_PASSWORD`. الإعدادات في `netlify.toml`.

## البنية

- `db/schema.ts` — Drizzle + Neon Postgres
- `lib/import/` — محلّلات ملفات الصندوق (xlsx) ومستخلصات إسلام (docx) + توحيد الأسماء
- `scripts/import.ts` — الاستيراد الكامل مع تقرير `data/import-report.txt`
- `app/actions/` — Server Actions (مصادقة، حسابات، مستخلصات، مطابقة، إعدادات)
